MobileGuard

Offline Android face recognition security application.

Features

- Offline face registration and recognition.
- Password-protected RED admin panel.
- Custom audio selection from device storage.
- Repeating audio alerts for unrecognized faces.
- Camera monitoring through Android foreground service.
- Local storage for face data and settings.
- No internet or paid API required.

Compatibility

- Android 16
- 32-bit ARM (armeabi-v7a)
